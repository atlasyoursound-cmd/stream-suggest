# Stream Suggest

Quoi passer ensuite sur Spotify, Deezer ou Apple Music : BPM, clé (roue Camelot) et énergie,
estimés sur l'extrait de 30 s de chaque morceau, directement dans le téléphone.

- Ouvrir la page, puis « Sur l'écran d'accueil » (iPhone/iPad) ou « Installer l'appli » (Android) pour l'avoir comme une appli.
- « Connecter Spotify » : suit le morceau en cours et ajoute les suggestions à la file d'attente (Spotify Premium).
- Suggestions : API publique Deezer. Aucun serveur, aucune donnée envoyée ailleurs que Deezer, Spotify et Apple (recherche de lien).
